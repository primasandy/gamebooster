# 🚀 TBOOST - Ultimate Gaming Booster
**Developed by: z1nxbabyyy**

TBOOST adalah tool optimasi performa HP Android (Tanpa Root) yang memanfaatkan API rahasia sistem (via Shizuku) untuk memaksa HP bekerja maksimal saat bermain game.

## ⚡ Fitur Utama
- **GOD MODE**: 1-klik optimasi total (CPU, RAM, DNS, Thermal).
- **Game Launch & Boost**: Buka game otomatis + kunci CPU ke Big Cores.
- **Resolution Override**: Turunkan resolusi game untuk FPS maksimal.
- **Thermal Bypass**: Cegah HP menurunkan performa saat panas.
- **Auto-Update**: Tarik update terbaru langsung dari GitHub.

## 📦 Cara Install
Buka Termux, lalu jalankan:
\`\`\`bash
curl -sL https://raw.githubusercontent.com/primasandy/gamebooster/main/install.sh | bash
\`\`\`

## 🛠️ Persyaratan
1. Aplikasi **Termux** (F-Droid).
2. Aplikasi **Shizuku** (Play Store) dalam keadaan aktif.
3. **Termux:API**.
